# Brand assets

`amgen-blue-logo.png` and `amgen-blue-logo.svg` were obtained from the official [Amgen Media Asset Library](https://www.amgen.com/newsroom/image-library), using its [blue-logo download](https://www.amgen.com/-/media/Themes/Global/Global/Global/images/migration/image-library/Amgen-Blue-Logos.zip).

The SVG's fill color is `#0063C3`. Additional proposed UI colors in the design document are application accents, not a verified corporate brand palette. Use the original logo with its aspect ratio preserved. The mockups describe an educational project and do not claim this is an official deployed Amgen service.
